## Что такое PhotoPrep?

**PhotoPrep** — бесплатное приложение для macOS, которое готовит фотографии для сайтов: помогает удалять посторонние логотипы локальными нейросетями, приводить кадры к одному формату, наносить собственный логотип и экспортировать оптимизированные файлы без EXIF и другой служебной информации.

**Сейчас: ранняя альфа, этап 6.** Работают импорт и просмотр фотографий, маска и рамка результата, локальный предпросмотр удаления LaMa / MI-GAN, сравнение «До / После», история, сохранение наборов, тёмное/светлое оформление и два языка. Работают PNG-логотипы и экспорт JPEG/PNG. Исходные файлы не изменяются, фотографии никуда не отправляются.

### Как попробовать

**[Скачать v0.1.0-alpha.16 для macOS Apple Silicon](https://github.com/sirdimitry/PhotoPrep/releases/tag/v0.1.0-alpha.16)** — DMG и контрольная сумма SHA256. Требуется **macOS 14+**; устанавливать Python отдельно не нужно. Перетащи PhotoPrep в Applications.

Это ранняя альфа с **ad-hoc подписью, без нотарификации Apple**: macOS может показать предупреждение при открытии скачанного приложения. Проверено на macOS 27.2 / Apple Silicon; Intel и другие версии macOS не проверялись. [Список изменений](CHANGELOG.md).

Запуск из исходников на macOS с Python 3.11+:

```bash
git clone https://github.com/sirdimitry/PhotoPrep.git
cd PhotoPrep
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m photoprep
```

### Управление

| Действие | Способ |
|:--|:--|
| Открыть фото | `⌘ O` |
| Открыть папку | `⌘ Shift O` |
| Открыть / сохранить набор | `⌘ ⌥ O` / `⌘ S` |
| Предыдущее / следующее фото | `←` / `→` |
| Убрать из набора | `Delete` |
| Отмена / повтор изменений набора | `⌘ Z` / `⌘ Shift Z` |
| Масштаб | Колесо мыши / прокрутка трекпада или кнопки `+ / −` |
| Передвинуть кадр | Инструмент выбора (`V`) или удерживание `Пробела` |
| Кисть / ластик / рамка | `B` / `E` / `C` |
| Размер кисти | `[` / `]` или ползунок |
| Вписать в рабочую область | `⌘ 0` |
| Показать 100% | `⌘ 1` |

Файл набора (`.photoprep.json`) хранит локальные пути к фотографиям и положение просмотра, без копий изображений. При открытии приложение сообщит об отсутствующих исходниках. Удаление из набора оставляет исходный файл на месте. История отменяет добавление и удаление фото, штрихи маски, проходы удаления, рамки и размеры результата. Исходные пиксели не изменяются. Наборы с шаблоном используют формат 6, с отдельным логотипом — формат 5: относительный путь к PNG и положение в рамке. Форматы 1/2/3/4/5 открываются. Без логотипа сохраняются прежние форматы. Ранние версии приложения не открывают новые форматы наборов.

Управление инструментами находится в правой панели, масштаб — над миниатюрами, короткое имя фото — рядом с названием приложения. Переключение инструментов не уменьшает окно просмотра. Рамка результата неподвижна: перемещай фото и меняй его масштаб колесом под рамкой. Её размер меняется только в настройках.

### Принципы

**Никакой облачной загрузки фотографий.** Исходники никогда не перезаписываются. AI должен менять только область, которую ты разрешил обработать. Все функции включаются по мере готовности, а не имитируются.

Нашёл ошибку или придумал улучшение? [Создай Issue](https://github.com/sirdimitry/PhotoPrep/issues). Приложение бесплатное, исходный код доступен под лицензией MIT.

### Локальная обработка (этап 4)

Нарисуй маску и нажми **«Удалить выделенное»** справа. В **«Настройки → Модели»** выбери LaMa (208,0 МБ) или MI-GAN (28,1 МБ).
Там доступны загрузка, проверка, удаление и переустановка. При отмене
переустановки установленный файл сохраняется. Недостающая модель загружается
при первой обработке, с проверкой HTTPS и SHA256. Фотографии и маски
никуда не отправляются. Расчёт работает отдельно от окна и отменяется кнопкой
«Отмена». Кнопки «До / После» или значок сравнения переключают вид.

Предпросмотр меняет только область маски; пиксели снаружи и прозрачность
сохраняются. Модель обрабатывает участок контекста в разрешении 512 × 512,
поэтому качество зависит от сцены и размера выделения. Поддерживаются фото до
40 мегапикселей. После удаления текущая маска очищается. Дорисуй новую область прямо на результате
и снова нажми «Удалить выделенное»: предыдущие удаления сохранятся. Очистка маски
затрагивает только текущее выделение. «До» показывает исходное фото, «После» —
результат всех проходов. Удаления также отменяются и повторяются через ⌘Z / ⌘⇧Z.

Последовательность масок сохраняется в наборе. После открытия нажми
«Восстановить ретушь», чтобы пересоздать накопленный результат. Для фото
поддерживается до 100 проходов удаления. Предпросмотры хранятся в ограниченном
кэше; при необходимости они восстанавливаются из сохранённых масок.
У каждого прохода сохраняется модель: переключение на другую не меняет уже
сделанную ретушь. При восстановлении набора приложение загрузит недостающие
модели и выполнит проходы в прежнем порядке, загружая одну модель за раз.
Следующий этап — проверка производительности и удобства на реальных наборах.

Временные маски и результаты удаляются после завершения или отмены. Исходники
остаются неизменными. Лицензии и авторство: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

### Логотип и готовые файлы

Инструмент логотипа (`L`): выбери PNG, перетаскивай его внутри рамки, меняй размер
и непрозрачность. «Последний» использует ранее выбранный PNG, «Включить лого на всех фото»
применяет расположение к набору. Изменения отменяются через ⌘Z. Логотип — до
32 мегапикселей и 32 МБ; при переносе набора нужен доступ к этому PNG.

«Экспорт» (`⌘ Shift E`) сохраняет текущее фото или весь набор рядом с каждым исходником,
в JPEG или PNG. Для JPEG регулируется качество. Размер совпадает с рамкой,
например **1136 × 710**. Выполненная ретушь восстанавливается автоматически;
неприменённую маску нужно обработать или очистить до экспорта.

Имена — `исходное-logo.jpg` / `.png`; для набора — `исходное-logo01.jpg`,
`другое-logo02.jpg` и далее. При совпадении выбирается следующий свободный номер.
Существующие файлы и исходники не перезаписываются. Пакет обрабатывается
последовательно в фоне. При отмене готовые файлы остаются, временные удаляются.

Выход — 8-битные JPEG или RGBA PNG в sRGB; прозрачность JPEG заменяется белым.
Из файлов удаляются исходные EXIF/GPS, XMP, комментарии, профили и текстовые
метки. Перед удалением профиля цвет приводится к sRGB. Исходные фото не
меняются. Для исходника и результата действует предел 40 мегапикселей.

### Локальные шаблоны логотипа

В инструменте логотипа нажмите **Папка…** и выберите свою папку PNG-шаблонов.
Первыми идут горизонтальные 16:9 слева сверху, затем справа сверху; остальные
варианты доступны в том же списке. Прозрачное поле шаблона распознаётся
автоматически: видимый знак сохраняет относительный размер и отступы при смене
рамки, без растягивания. Размер результата при выборе шаблона не меняется.
Режим **Отдельный логотип** предназначен для PNG с одним знаком и альфаканалом.
Размер, положение и непрозрачность можно корректировать в обоих режимах.
Пути сохраняются локально; ваши шаблоны не копируются в приложение или GitHub.

### Сохранение и сравнение

Экспорт не создаёт отдельную папку: каждый готовый файл сохраняется рядом со
своим исходником. Для одного фото используется `фото-logo.jpg` или `.png`, для
нескольких — `фото-logo01.jpg`, `другое-logo02.jpg` и далее. Занятые имена
пропускаются, файлы не перезаписываются.

«До / После» осталось только слева. Переключатель доступен после маски,
кадрирования, ретуши, логотипа и изменения размера результата. «До» показывает
исходные пиксели без маски и логотипа, с начальной направляющей кадра; «После»
возвращает изменения. Сравнение не удаляет настройки фото.

### Порядок работы и «О программе»

После импорта открывается маска удаления. Инструменты слева идут по порядку:
маска, ластик маски, рамка, перемещение, свой логотип, сравнение. Размер рамки
сохраняется, фотографию можно двигать и масштабировать внутри неё.
Имя в заголовке использует всю ширину до «Открыть фото»; если оно не помещается,
сохраняются начало и конец имени, а середина заменяется на `...`.

В настройках есть раздел «О программе»: полный текст MIT, пояснение об
использовании логотипов и ссылка [@sirdimitry в X](https://x.com/sirdimitry).
Сторонние логотипы и брендированные шаблоны не включены в релиз. Пользователь
сам выбирает изображения и отвечает за наличие прав на их использование;
лицензия MIT на PhotoPrep не предоставляет прав на чужие знаки.

### Логотип на всём наборе

Панель соответствует текущему фото. Если логотип не применён, параметры его
расположения скрыты, а в списке шаблонов нет активного выбора.
**«Включить лого на всех фото»** использует текущий или последний настроенный
знак, включает его на всём текущем наборе и сразу обновляет видимое фото.
Ретушь и рамка сохраняются; действие отменяется одним шагом.

Для набора из нескольких фото экспорт по умолчанию выбирает **все фото**.
JPEG или PNG выбирается один раз для всего набора. Возможность сохранить только
текущее фото остаётся. Имена `-logo` и сохранение рядом с исходниками сохраняются.

### Дополнительная SDXL Inpainting

В «Настройки → Модели» есть SDXL Inpainting рядом с LaMa и MI-GAN. До скачивания
карточка объясняет: если остались разводы, дорисуйте маску и повторите обработку
лёгкой моделью либо попробуйте SDXL для сложного фона. Она медленнее, результат
зависит от фото. FP16-веса — **18 файлов, 6 941 218 469 байт (6,94 ГБ)**; скачиваются
отдельно. Полная сборка содержит нужные библиотеки, но не сами веса.

SDXL работает локально через GPU Apple Silicon (Metal), с контекстом 1024 × 1024,
20 шагами, фиксированными описанием фона и seed. В итог вклеивается только точная
исходная маска; пиксели вне неё и альфаканал сохраняются. Можно чередовать SDXL,
LaMa и MI-GAN; при восстановлении и экспорте загружается одна модель за раз.
Наборы с проходами SDXL используют формат 7; форматы 1–6 открываются.

Тестовый проход на M3 Max / 36 ГБ занял около 56 секунд с проверкой и загрузкой
модели в память. Это один замер, а не гарантия скорости или качества. При нехватке
памяти закройте тяжёлые приложения или используйте LaMa/MI-GAN. Для исходников
зависимости SDXL устанавливаются в существующее окружение; новый Python не нужен.
Лицензия модели CreativeML Open RAIL++-M отличается от MIT самого приложения.

### Локальный технический журнал

Журнал записывает запуски, операции с моделями, ошибки обработчиков и сети.
Пункта в GUI и автоматической отправки нет. Один файл очищается, если следующая
запись превысит 10 МБ. Токены, пароли и параметры подписанных ссылок скрываются.
При сетевом обрыве загрузка SDXL повторяется и продолжает частичный файл в пределах
текущей операции. Неудача или отмена не удаляет ранее установленную модель.

### Подключить модель с диска

У каждой модели есть **«Выбрать на диске…»**: ONNX-файл для LaMa/MI-GAN или полная
официальная папка FP16 для SDXL. Проверяются точная поддерживаемая inpaint-версия,
размеры и SHA256 всех файлов. Обычные text-to-image checkpoint, FP32-варианты
и неполные папки не подключаются. Исходные файлы не меняются. На одном диске
можно обойтись без второй физической копии; с другого диска файлы копируются
в служебную папку приложения.

Обычная загрузка сначала проверяет установленную модель, затем сохранённые
локальные источники и официальный кэш нужной версии. Подходящие файлы используются
без сети. Принудительное скачивание выполняется только по «Переустановить».

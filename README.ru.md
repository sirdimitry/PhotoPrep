## Что такое PhotoPrep?

**PhotoPrep** — бесплатное приложение для macOS, которое готовит фотографии для сайтов: помогает удалять посторонние логотипы локальными нейросетями, приводить кадры к одному формату, наносить собственный логотип и экспортировать оптимизированные файлы без EXIF и другой служебной информации.

**Сейчас: ранняя альфа, этап 1.** Работают каркас редактора, импорт фотографий, лента миниатюр, масштабирование, перемещение, тёмная тема, настройки и два языка. **Удаление логотипов, кадрирование и экспорт ещё не реализованы.** Фотографии никуда не отправляются.

### Как попробовать

**[Скачать v0.1.0-alpha.2 для macOS Apple Silicon](https://github.com/sirdimitry/PhotoPrep/releases/tag/v0.1.0-alpha.2)** — DMG и контрольная сумма SHA256. Требуется **macOS 14+**; устанавливать Python отдельно не нужно. Перетащи PhotoPrep в Applications.

Это ранняя альфа с **ad-hoc подписью, без нотарификации Apple**: macOS может показать предупреждение при открытии скачанного приложения. Проверено на macOS 27.2 / Apple Silicon; Intel и другие версии macOS не проверялись. [Список изменений](CHANGELOG.md).

Запуск из исходников на macOS с Python 3.11+:

```bash
git clone https://github.com/sirdimitry/PhotoPrep.git
cd PhotoPrep
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m photoprep
```

### Управление

| Действие | Способ |
|:--|:--|
| Открыть фото | `⌘ O` |
| Открыть папку | `⌘ Shift O` |
| Масштаб | Колесо мыши / прокрутка трекпада или кнопки `+ / −` |
| Передвинуть кадр | Перетаскивание фотографии |
| Вписать в рабочую область | `⌘ 0` |
| Показать 100% | `⌘ 1` |

### План разработки

0. **Дизайн:** иконка, фирменный стиль, GitHub-баннер.
1. **Интерфейс:** рабочее окно, открытие фото, миниатюры, RU/EN — текущий этап.
2. **Базовая логика:** состояние документа, навигация, история.
3. **Маска и кадрирование:** кисть, ластик, фиксированная рамка.
4. **AI-ретушь:** локальная LaMa и восстановление только внутри маски.
5. **Модели:** проверенный каталог, загрузка с прогрессом, контроль целостности.
6. **Логотип и экспорт:** собственный логотип, JPEG/PNG, удаление метаданных.
7. **Релизы:** оптимизация, сборка DMG и проверка на macOS.

### Принципы

**Никакой облачной загрузки фотографий.** Исходники никогда не перезаписываются. AI должен менять только область, которую ты разрешил обработать. Все функции включаются по мере готовности, а не имитируются.

## 2. Что было исправлено в качестве

Сравнение шло по шагам, а не только по финальной картинке. Для astronaut (512×512, одинаковые три штриха, Python `inpaint` и Native worker):

| Шаг | Результат |
|---|---|
| ориентированный source | **идентичен**, max 0 |
| context rect | **идентичен**: `0,0,354,354` |
| полная маска до 512 | max 12/255, mean 0.0026; 350 пикселей различаются |
| RGB-тензор 512×512 | max **0.00199** (≈0.51/255), mean 0.00095; 0 пикселей >1/255 |
| mask-тензор 512×512 | **5 пикселей** различаются |
| выход модели | max **16.19**, mean 0.411; было max 36.09/mean 0.480 |
| финальный композит | max **13**, mean 0.083; было max 34/mean 0.105 |

Для coffee (600×400): image512 max 0.00199, mask512 1 пиксель, model max 13.19, final max 13/mean 0.056.  
Для grass (CC0, 512×512, сложная фактура): image512 max 0.00199, mask512 5 пикселей, model max 20.06, final max 16/mean 0.118.

Найдены и исправлены **конкретные причины**, а не «фильтр масштабирования»:

1. **Clamp вне context rect.** Bilinear на последней строке/столбце брал пиксель за границей crop; это давало до 22/255 на краю. Теперь clamp ограничен `rect`.
2. **Float → uint8 не в том месте.** Python делает `np.clip(pred,0,255).astype(uint8)` **до** обратного масштабирования. Native интерполировал float и округлял только при композите. Теперь Native сначала clip+truncate в UInt8, затем масштабирует.
3. **Маска масштабировалась не тем путём.** Для mask используется Qt-совместимый fixed-point upscaler (8-битные веса, truncation); для RGBA8888 Python идёт через QPainter bilinear, поэтому RGB оставлен на измеренном bilinear. После этого mask512: 37 → 5 пикселей.
4. **Astronaut-ghost** исчез: на 100% и 200% в области `EDGE` больше нет выдуманного лица/волос; остаётся отличие фактуры/hair edge от Python.

Остаточные артефакты:

* 5 пикселей mask-тензора (край round cap) и 0.002 RGB-тензора всё ещё дают model max 16/ final max 13; визуально это не ghost, но blind-паритет не заявлен.
* На траве LaMa (и Python, и Native) размывает высокочастотную фактуру в верхнем левом углу; Native не хуже Python по структуре, но качество на таком домене не принято.
* 200% astronaut: Native и Python по-разному продолжают hair/face edge; это оставшийся quality gap.

## 3. Отмена, гонки и ошибки

* Отмена принадлежит **конкретному job**: `CancellationFlag` + `retouchActiveID`; старый job не сбрасывает флаг нового.
* После cancel/timeout `retouchBusy` остаётся `true`, пока task/worker не подтвердит завершение; новый тяжёлый worker в это время не запускается. Файлы job удаляются после подтверждённого выхода через `defer`.
* Старое завершение не очищает ссылку на новый job: очистка идёт только при совпадении `retouchActiveID`.
* `cancelRetouch` больше не выставляет `busy=false` сразу; UI показывает «Отмена…», пока процесс жив.
* Cancellation flag проверяется в `prepare` (по строкам), `composite` (по строкам), `mask render` (между штрихами) и в worker loop. ImageIO decode не прерывается; после decode проверяется флаг.
* Ошибки разделены:
  * отсутствующая модель — **обычная ошибка** `model_load_failed`;
  * настоящий crash — SIGKILL, ожидается `processExited(9)`;
  * зависание — timeout 0.2 s, ожидается `timedOut`;
  * отмена до запуска — `cancelled` без процесса;
  * cancel → новый запуск — второй job успешен.

Фактические self-tests (final build):

```text
failure self-test: ordinary error model_load_failed
hang self-test: timed out and worker stopped
crash self-test: worker crashed with status 9
cancel-before-start self-test: cancelled before launch
cancel self-test: cancelled
cancel self-test: restart after cancel ok
pressure self-test: warning=true critical=true ok=true
```

## 4. Decoder

* Принимается только RGB color space; **CMYK отклоняется** (`unsupported_color`), есть тест.
* Проверяются `bitsPerComponent=8`, `bitsPerPixel=24/32`, alphaInfo, byte order, `bytesPerRow`, длина CFData.
* `noneSkipFirst/Last` **не трактуются как RGBA**: RGBX/XRGB явно разбираются как RGB + alpha 255. CMYK, alphaOnly, float, non-default byte order и неизвестные layout отклоняются.
* Premultiplied alpha с alpha<255 отклоняется; hidden RGB сохраняется; straight alpha не меняется.
* ICC-профиль сохраняется в `StraightImage.iccProfile` и прикладывается к `CGImage` при отображении; **цветовая конверсия не выполняется**. Это политика E1.1: байты исходника не пересчитываются, ICC нужен для показа.
* JPEG orientation 6 full decode по-прежнему проходит.

## 5. Ресурсы

* Добавлен combined retouch budget: app buffers + worker reservation 768 MiB + resident; оценка источника/маски/результата/512-тензоров; лимит `min(4 GiB, physical/3)` и системный резерв 2 GiB.
* 40 Мп проходит; 16 ГБ/8 ГБ не проверялись, поэтому это оценка, а не доказательство для слабого железа.
* Memory pressure warning/critical проверены **инъекцией в модель** (`memoryPressure(.warning/.critical)`), не реальным OS pressure source.
* Cancellation подготовки/композита останавливает циклы; маска — между штрихами; decode — только после завершения ImageIO.

## 8. Ограничения E1.1

* Нет native 40 Мп фото; 40 Мп — upscaled real coffee.
* Нет полного blind 100/200% приёма; есть 100/200% сравнения astronaut/coffee/grass и остаточные отличия.
* На траве высокочастотная фактура размывается; это свойство LaMa/Python, но качество не принято.
* Mask512 всё ещё 5 пикселей, model max 16, final max 13; 5 пикселей — край round cap.
* Нет 8/16 ГиБ, Intel, macOS 14; только Apple M3 Max 36 ГиБ, macOS 27.2.
* Нет реального memory pressure event; injection только в модель.
* Нет UI-сценариев NSOpenPanel, photo switch, source substitution, 20 UI passes.
* Worker — self-exec Process, не XPC; lifecycle остаётся как E1.
* Crop/logo/export/sessions/other models/FP16/quantization не входят.

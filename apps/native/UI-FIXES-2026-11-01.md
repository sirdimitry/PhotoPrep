## Fixed

* CropCanvas now uses the same non-flipped NSView orientation as BrushCanvas; crop no longer turns the photo upside down.
* Canvas geometry uses the oriented document dimensions, not the display buffer dimensions. Preview/result resolution changes do not zoom or shift.
* One viewport state per photo: Fit, 100%, +/- and pan. 100% is one source pixel per backing pixel; pan from Fit preserves the current visual scale.
* Fixed top/left ruler bands with image-pixel units; ticks and labels follow zoom/pan. Frame is drawn from the same crop used by export; crop frame remains fixed while the image moves under it.
* Brush cursor circle with actual diameter (source-pixel label); mask painted immediately; mask visibility is independent of before/after.
* Eraser affects only the mask; pass undo remains separate.
* Other tools no longer draw masks; logo/comparison are view-only.
* Crop session: Done commits, Cancel restores pre-entry crop, Undo history is action-level with a 20-entry cap.
* Logo is loaded into the canvas layer and drawn with the same geometry/alpha as export; explicit Logo/Overlay mode, full overlay canvas preserved, filename/parameters shown.
* Thumbnails: 120×80 limited ImageIO decode off-main with bounded cache; middle-truncated name; file-info popover; no duplicate properties.
* Typed crop/orientation regression test added; 37 Swift tests pass.

## Iteration 5 — target UX rework

**Code:** `40e2f21`  
**Build:** `work/PhotoPrep-Native-v1-final-check.app`  
**Tests:** 37 Swift tests pass.

### Changed

* Removed the bottom status row; canvas receives the height.
* Removed the internal duplicate title/action strip. The native macOS title bar shows `PhotoPrep Native v1 — <file>`; the action panel below it is gone.
* Removed bottom zoom bar; files, settings, zoom, tool parameters and export now live in the fixed-width right inspector. Export is a pinned bottom block with format, JPEG quality only for JPEG, and the large yellow Export button.
* Removed Move and Before/After tools. Space/mouse/pinch/wheel navigation remains.
* Brush/eraser cursor is a separate `CursorOverlayView` child layer, not part of the mask draw path. It follows mouseMoved/global monitor, is thin (1/backing-scale), hides outside/other tools, and does not redraw the photo.
* Crop drag moves the image under the fixed frame in both axes. On mouse-up, a 10-screen-pixel edge snap is applied to the crop edges; the snap is release-time to avoid fighting precise drags.
* Added custom vector-like `Logo` rail glyph with tooltip.
* Logo scale UI: logarithmic slider 1–10000%, center/marked 100%, numeric percent field and reset button. 100% means source logo width in output pixels; the model accepts sizes beyond the output frame.
* Logo drag overlay with open/closed hand cursor and native drag; no selection outline except hover.
* Logo state is persisted in UserDefaults with a security-scoped bookmark; loaded on app start/import. File is not copied into app/resources.

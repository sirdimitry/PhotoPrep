## Fixed

* CropCanvas now uses the same non-flipped NSView orientation as BrushCanvas; crop no longer turns the photo upside down.
* Canvas geometry uses the oriented document dimensions, not the display buffer dimensions. Preview/result resolution changes do not zoom or shift.
* One viewport state per photo: Fit, 100%, +/- and pan. 100% is one source pixel per backing pixel; pan from Fit preserves the current visual scale.
* Fixed top/left ruler bands with image-pixel units; ticks and labels follow zoom/pan. Frame is drawn from the same crop used by export; crop frame remains fixed while the image moves under it.
* Brush cursor circle with actual diameter (source-pixel label); mask painted immediately; mask visibility is independent of before/after.
* Eraser affects only the mask; pass undo remains separate.
* Other tools no longer draw masks; logo/comparison are view-only.
* Crop session: Done commits, Cancel restores pre-entry crop, Undo history is action-level with a 20-entry cap.
* Logo is loaded into the canvas layer and drawn with the same geometry/alpha as export; explicit Logo/Overlay mode, full overlay canvas preserved, filename/parameters shown.
* Thumbnails: 120×80 limited ImageIO decode off-main with bounded cache; middle-truncated name; file-info popover; no duplicate properties.
* Typed crop/orientation regression test added; 37 Swift tests pass.

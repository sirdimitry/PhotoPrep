## Scope and limits

Session formats 1–7 remain readable with the existing writer/schema logic.
Automated regressions cover sessions, undo/redo, retouch, crop, branding, export,
model catalogue/import and SDXL behavior. Full manual interaction with every tool
and a new model download were not repeated for this release. Existing local weights
were reused. Native SwiftUI/Core ML behavior is not implemented or validated here.

Local build attempts and validation logs are retained under ignored `work/`;
only the DMG and SHA256 are intended release attachments. Earlier releases remain
available. The native migration has explicit parity and data-preservation gates.
